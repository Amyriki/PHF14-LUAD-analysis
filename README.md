# PHF14 genomic analysis in lung cancer

This repository contains an exploratory analysis of PHF14-associated
expression and copy-number patterns in TCGA lung cancer datasets.

The analysis currently includes lung adenocarcinoma (LUAD) and lung
squamous cell carcinoma (LUSC).

## Notebooks

- `01_PHF14_LUAD_analysis.ipynb` — TCGA-LUAD analysis
- `02_PHF14_LUSC_analysis.ipynb` — TCGA-LUSC analysis
